## 課題

日本国内には多様な方言が存在しますが、コミュニケーションや地域文化の保全において以下のような課題が生じています。
① 日常会話での意図しないすれ違い・ニュアンスの誤解
- 京都の皮肉・婉曲表現: 「ええ時計したはりますなぁ」という言葉が、文字通りの褒め言葉ではなく「長居せずに早く帰ってほしい」という意図であるように、言葉の裏にあるコンテキスト（文脈）を知らないとすれ違いが発生します。
- ローカル単語の壁: 愛知県の「ケッタ（自転車）」のように、本人たちは日常的に使っている標準語だと思っていても、他地域の友人には意味が伝わらない事例が多発しています。
② フォーマルな場面（書類・レポート等）での方言混入
- 地元を離れて大学進学や就職をした人が、公的な書類・レポート・ビジネスメールを作成する際、無意識に方言を含めてしまい不適切になるケースがあります。
③ 消滅の危機に瀕する方言文化の保護
- 若年層を中心に日常会話の標準語化が進み、伝統的な方言や地域独特の表現が失われつつあります。高齢者の減少とともに語り継ぎが難しくなっている地域言語の維持・保存が急務となっています。

## 解決方法

特長 1: リアルタイム双方向変換 & 方言注釈表示
- 入力した文章を「標準語 ⇆ 方言」へと即時に相互変換します。
変換時、「これは〇〇（例: 京都）の方言・表現です」といった注釈やニュアンスの補足を表示し、文脈の理解を助けます。

特長 2: 複数地域の方言マルチ比較
- 変換先の地域を同時に複数選択可能。同じフレーズが関西・東北・九州などでどのように変化するかを簡単に比較・発見でき、旅行先でのコミュニケーションや学習にも活用できます。

特長 3: 国立国語研究所『COJADS』データを活用した高精度な語彙基盤
- 国立国語研究所が提供する「日本語書き言葉生コーパス」等のオープンデータや学術的データベース（COJADS等）を統合・活用。単なる単語置換にとどまらない、文脈に即した高精度な変換アルゴリズムを実装しています。
